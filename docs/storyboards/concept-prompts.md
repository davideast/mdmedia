# Intaglio storyboard concept artwork

Four generated planning images for the fictional Veil product. These are visual targets, not recorded screens or a functioning product. Narration, visual direction, timing estimates, and notes live in `intaglio-expanded.storyboard.json`. The earlier outline remains in `intaglio.storyboard.json`.

## modern

Asset: `studio/public/assets/storyboard/modern.png`

Create one landscape 16:9 storyboard concept frame: a beautifully competent modern desktop landing page for fictional virtual-card brand VEIL. Full page UI fills frame, no laptop or browser chrome. Off-white background, polished violet and blue gradients, soft shadows, rounded rectangular virtual credit card on right, hero left reads 'Your card. Your rules.' and subheading 'Virtual cards for everyday payments.' with button 'Create a card'. Navigation VEIL, How it works, Your controls. Below hero three compact cards: Merchant lock, Spending limits, Pause anytime. Large clean typography, credible fintech art direction. Card uses fake number 4242 and label VIRTUAL. This is the BEFORE design in a redesign storyboard. Avoid busy tiny text.

## engraving

Asset: `studio/public/assets/storyboard/engraving.png`

Create one landscape 16:9 visual direction board for a fictional virtual-card service VEIL. Cream cotton paper, dark forest green ink, copperplate intaglio-inspired fine engraved crosshatching. Large ornate engraved shield with small keyhole center, botanical border, guilloche circular line patterns and elegantly engraved rectangular payment card marked VEIL. An editorial specimen sheet with generous whitespace, extremely fine linework, refined banknote aesthetic. Small heading 'A different kind of confidence'. Flat graphic artwork, no photography, no mockup device, no gradients. Clear distinguishable elements useful for a storyboard about financial visual identity.

## controls

Asset: `studio/public/assets/storyboard/controls.png`

Create one landscape 16:9 storyboard concept frame: close-up desktop interface for fictional virtual-card product VEIL, intaglio-inspired finance design. Warm ivory background, forest-green text, readable sans serif controls, elegant serif heading 'You set the limits.' Left an engraved rectangular virtual card VEIL / VIRTUAL / 4242 with subtle guilloche border. Right a clean practical settings panel with 'Merchant' and 'Field Supply', 'Monthly limit' and '$150', 'Card status' and 'Active', a simple prominent 'Pause card' button. Tiny engraved botanical ornament only at outer corner, restrained texture, large readable controls. Polished flat graphic UI, no gradients, no device, no photography. Show how distinctive engraving decoration can coexist with utilitarian clear settings.
